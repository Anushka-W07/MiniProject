# Data

## `samples/` (included)
Generated by `python scripts/generate_samples.py` from the physics-based simulator in `astrosense/backend.py`.
**This is simulated data, not real telemetry.**

| File | Content |
|---|---|
| `sample_healthy_training.csv` | 3000 rows of healthy telemetry (one propellant lifetime, 23 to 6 bar). Use as the training baseline. |
| `sample_telemetry_log.csv` | 300 rows with three injected faults: CO2 scrubber degradation (rows 80-160), engine overheating and propellant leak (rows 180-260). |

## Real datasets (download yourself into `data/raw/`, which is git-ignored)
| Dataset | Link | Use in this project |
|---|---|---|
| OPSSAT-AD (ESA OPS-SAT CubeSat) | https://doi.org/10.5281/zenodo.12588359 | File > Load OPS-SAT-AD dataset.csv. Trains on normal segments, reports precision / recall / F1 on held-out segments. |
| ESA-ADB (3 ESA missions) | https://doi.org/10.5281/zenodo.12528696 | Not wired into the GUI yet. Future work. |

OPSSAT-AD holds pre-computed signal features, not named sensors such as battery voltage.
